📚 Partikel Dasar

1. Partikel Subjek: 이/가

저는 학생이에요. (Jeoneun haksaengieyo.)

Saya adalah pelajar.

2. Partikel Objek: 을/를

밥을 먹어요. (Babeul meogeoyo.)

Saya makan nasi.

3. Partikel Lokasi: 에

학교에 가요. (Hakgyoe gayo.)

Saya pergi ke sekolah.

📚 Konjugasi Kata Kerja

1. Bentuk Present: -아/어요

먹다 → 먹어요 (meokda → meogeoyo)

Makan → Saya makan

2. Bentuk Past: -았/었어요

먹다 → 먹었어요 (meokda → meogeosseoyo)

Makan → Saya sudah makan

3. Bentuk Future: -을 거예요

먹다 → 먹을 거예요 (meokda → meogeul geo yeyo)

Makan → Saya akan makan

💡 Tips Belajar

1. Pahami fungsi setiap partikel
2. Latihan membuat kalimat sederhana
3. Hafalkan konjugasi dasar
4. Baca dan terjemahkan teks Korea
5. Praktik berbicara setiap hari
